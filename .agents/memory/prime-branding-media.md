Finish and industry cards use files served from the API media library (`/api/uploads/...`) rather than bundling separate frontend copies.

**Why:** The user rejected generic catalogue references and asked for branded, finish-specific images that remain connected to the project's media library.

**How to apply:** Add replacement images to the API uploads/media flow first, then reference their canonical `/api/uploads/...` URLs from storefront and CMS content.
